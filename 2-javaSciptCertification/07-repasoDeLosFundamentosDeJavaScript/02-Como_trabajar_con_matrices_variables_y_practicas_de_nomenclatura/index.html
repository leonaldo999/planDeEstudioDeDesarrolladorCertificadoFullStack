🚀 Introducción

En esta sección, aprenderás a trabajar con matrices, variables y prácticas de nomenclatura en JavaScript. Las matrices son estructuras de datos que pueden almacenar múltiples valores en una sola variable. Las variables son contenedores para almacenar datos y las prácticas de nomenclatura ayudan a mantener tu código organizado y fácil de entender.

Tema 1: ¿Cuáles son algunas prácticas comunes para nombrar variables y funciones?

Nombrar variables y funciones es un aspecto importante para escribir código limpio, legible y fácil de mantener. Las buenas prácticas de nomenclatura hacen que tu código se documente por sí mismo, lo que reduce la necesidad de comentarios extensos y facilita que otros desarrolladores —incluido tu yo futuro— entiendan tu código.

Comencemos con las convenciones generales de nomenclatura en JavaScript. En lecciones anteriores aprendiste a usar el estilo camel case para los nombres de variables. Para las variables booleanas, es una práctica común usar prefijos como is, has o can. Esto le indica de inmediato al lector que la variable es booleana:

123 
let isLoading = true;
let hasPermission = false;
let canEdit = true;

Seguimiento Matricial Combinado

Historial de Coordenadas (i, j):
🟢 isLoading: Uso de camelCase combinado con el prefijo interrogativo/afirmativo 'is'. Auto-documenta que el sistema se encuentra esperando un proceso asíncrono.
🟢 hasPermission: El prefijo 'has' denota posesión o cumplimiento de una propiedad o rol en el sistema de dependencias.
🟢 canEdit: El prefijo modal 'can' expresa una capacidad o derecho de ejecución de una acción por parte de la entidad actual.
MEMORY STATE AUDIT:
↳ isLoading ➔ type: boolean, value: true
↳ hasPermission ➔ type: boolean, value: false

Al nombrar variables de iteración y bucles, es común usar letras únicas como i, j o k, pero para bucles anidados o iteraciones más complejas, puede ser útil usar nombres más descriptivos:

1234567

  /* ... */
}

for (let studentIndex = 0; studentIndex < students.length; studentIndex++) {
  /* ... */
}

Seguimiento Matricial Combinado

Historial de Coordenadas (i, j):
🟢 Uso de 'i': Ideal para operaciones abstractas rápidas donde el contenedor (array) es genérico. Reduce caracteres redundantes cuando el contexto es autoevidente.
🟢 Uso de 'studentIndex': Añade valor semántico explícito. Al leer el cuerpo interno del bucle, el desarrollador asocia inmediatamente el índice con la entidad de negocio students[studentIndex], previniendo confusiones si se añadieran sub-bucles para procesar notas o asistencias.
ITERATION CONTEXT TRACE:
• Bucles lineales sencillos ➔ Variable corta admisible (i).
• Estructuras multidimensionales / Complejas ➔ Variable descriptiva imperativa (studentIndex).

Tema 2: ¿Cómo se obtiene la longitud de un array y cómo se puede crear un array vacío de longitud fija?

En lecciones anteriores ya conociste la propiedad length esta propiedad devuelve el número de elementos que contiene un array. Así que aquí tienes un breve recordatorio de cómo funciona:

12 
const fruits = ['apple', 'banana', 'orange'];
console.log(fruits.length); // 3

Seguimiento Matricial Combinado

Historial de Coordenadas (i, j):
🟢 Mapeo de Índices en Memoria:
  • fruits[0] ➔ 'apple'
  • fruits[1] ➔ 'banana'
  • fruits[2] ➔ 'orange' (Índice máximo: 2)
🟢 Cómputo de la Propiedad: El motor lee la propiedad interna de control de tamaño. Al ser el índice máximo $2$, el valor de length se establece directamente como $2 + 1 = 3$.
CONSOLE:
3

Es posible tener arrays con celdas vacías. Las celdas vacías se definen como aquellas que no contienen nada. Esto es diferente a un array cuyo valor sea undefined. Este tipo de arrays se conocen como arrays dispersos. A continuación, un ejemplo:

12 
const sparseArray = [1, , , 4];
console.log(sparseArray.length); // 4

Seguimiento Matricial Combinado

Historial de Coordenadas (i, j):
🟢 Mapa Físico en Memoria V8:
  • index 0 ➔ 1
  • index 1 ➔ <empty slot> (no inicializado)
  • index 2 ➔ <empty slot> (no inicializado)
  • index 3 ➔ 4 (Índice máximo detectado: 3)
🟢 Cálculo de Longitud: El motor no cuenta elementos reales; calcula la longitud mediante la fórmula $i_{max} + 1$. Al ser el último índice asignado el $3$, la propiedad length se establece en $3 + 1 = 4$. Los métodos iterativos tradicionales como .forEach() o .map() omitirán automáticamente estos huecos vacíos.
CONSOLE:
4

💡 Alternativa limpia en Clean Code: Si notas que tu código empieza a requerir muchas etiquetas para controlar bucles complejos, a menudo es un indicador de que el bloque interno debería ser extraído y aislado dentro de su propia función independiente, utilizando una sentencia return para salir limpiamente del proceso.

En este caso, aunque solo tengamos dos elementos definidos, el 1 y el 4, la longitud es 4 porque el índice más alto (3) más 1 nos da una longitud de 4.

Ahora veamos cómo crear un array vacío de longitud fija. Hay varias formas de hacerlo en JavaScript, pero un método común es usar el constructor Array() con un argumento numérico. El constructor Array() se puede usar con la palabra clave new para crear un nuevo array. Aquí hay un ejemplo:

123 
const emptyArray = new Array(5);
console.log(emptyArray.length); // 5
console.log(emptyArray); // [ , , , , ]

Seguimiento Matricial Combinado

Historial de Coordenadas (i, j):
🟢 Instanciación con Argumento Numérico: El constructor detecta un único número entero positivo. En lugar de crear un arreglo con el elemento 5, configura la propiedad interna length: 5 de forma imperativa.
🟢 Estructura de Celdas Asignadas: El mapa físico en memoria no contiene propiedades indexadas válidas. En la consola, se renderiza con comas consecutivas separadas por espacios vacíos [ , , , , ], confirmando que contiene 5 ranuras vacías (empty x 5) que no responderán a métodos de mapeo convencionales hasta que sean inicializadas.
CONSOLE:
5
Array(5) [ <5 empty slots> ]

💡 Alternativa limpia en Clean Code: Si notas que tu código empieza a requerir muchas etiquetas para controlar bucles complejos, a menudo es un indicador de que el bloque interno debería ser extraído y aislado dentro de su propia función independiente, utilizando una sentencia return para salir limpiamente del proceso.

En este ejemplo, creamos un nuevo array utilizando Array(5). Esto crea un array disperso de longitud 5 en el que todas las posiciones están vacías.

Otra forma de crear un array vacío de longitud fija es utilizar el método Array.from() con un argumento de longitud. A diferencia de new Array(n), este método crea un array de la longitud especificada en el que todos los elementos existen y tienen un valor undefined:

123 
const fixedLengthArray = Array.from({ length: 5 });
console.log(fixedLengthArray.length); // 5
console.log(fixedLengthArray); // [undefined, undefined, undefined, undefined, undefined]

Seguimiento Matricial Combinado

Historial de Coordenadas (i, j):
🟢 Procesamiento del Objeto Like-Array: Array.from() recibe un objeto con la propiedad length: 5. Esto le indica al método cuántas iteraciones debe ejecutar internamente.
🟢 Creación y Asignación Real: A diferencia de los huecos vacíos, el algoritmo crea las propiedades de índice ("0", "1", etc.) en el objeto del arreglo y les asigna el valor real de retorno por defecto: undefined. Todas las celdas quedan inicializadas físicamente en memoria.
CONSOLE:
5
Array(5) [ undefined, undefined, undefined, undefined, undefined ]

Si quieres crear un array de una longitud específica y llenarlo con un valor por defecto, puedes usar el método Array.fill():

12

console.log(filledArray); // [0, 0, 0]

Seguimiento Matricial Combinado

Historial de Coordenadas (i, j):
🟢 Paso 1 (new Array): Reserva un array disperso con length: 3 conteniendo ranuras vacías (empty slots).
🟢 Paso 2 (.fill): El motor V8 ejecuta una mutación in-place iterando sobre las claves lógicas, reemplazando el vacío y enlazando el valor primitivo estático 0 en las coordenadas indexadas 0, 1 y 2 de forma secuencial.
CONSOLE:
[ 0, 0, 0 ]

💡 Alternativa limpia en Clean Code: Si notas que tu código empieza a requerir muchas etiquetas para controlar bucles complejos, a menudo es un indicador de que el bloque interno debería ser extraído y aislado dentro de su propia función independiente, utilizando una sentencia return para salir limpiamente del proceso.

Esto crea un array de longitud tres y llena todos los elementos con el valor 0. Nota: al llenar con objetos, todas las posiciones hacen referencia al mismo objeto; si necesitas copias independientes, utiliza una función de retorno o Array.from() en su lugar.

Entender cómo obtener la longitud de un array y crear arrays de longitud fija es importante para muchas tareas de programación, especialmente cuando necesitas inicializar arrays para algoritmos o estructuras de datos específicos.
