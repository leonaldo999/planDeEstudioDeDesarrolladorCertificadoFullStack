# Implementa el algoritmo `Slice and Splice`

En este laboratorio, deberás crear un algoritmo para fusionar dos arrays.

---

## Historias de usuario

1. Crea una función llamada `frankenSplice` que acepte dos arrays y un índice.

2. Copia cada elemento del primer array al segundo array, en orden, comenzando en el índice dado, y devuelve el array resultante.

3. Los arrays de entrada deben permanecer iguales después de que se ejecute la función.
